# OSR Updater 使用指南

## 操作前准备

- 使用为该控制器提供的固件文件，或你明确为 ESP32-S3 控制器开发的文件。
- 操作期间保持车辆静止并使用稳定电源。
- 停止 ROS 以及所有可能打开控制器串口的程序。
- 安装过程中不要断开 USB 或电源。

## 选择固件

OSR Updater 只有一个固件文件选择入口，客户端按照文件内容自动分类：

- **应用程序更新**：通过当前控制器固件安装 ESP-IDF App；要求当前固件提供
  OSR App OTA 命令，并且不擦除设置分区。
- **完整烧写镜像**：擦除控制器，并从 Flash 地址零开始写入合并镜像；镜像可以
  使用客户自行开发的分区布局。

客户端不内置固件。请将界面显示的 SHA-256 与固件随附校验值进行对照。

## 保护车辆设置

完整 NVS 分区包含出厂测试和车辆标定数据，重新测试这些参数的成本较高。
每次完整烧写前，OSR Updater 都会在 ROM 恢复模式下读取当前完整 NVS，保存一份
与控制器绑定的私有快照。用户不需要判断控制器是否仍处于“出厂状态”。

## 安装应用程序

1. 检查控制器。
2. 选择应用程序文件，核对类型和 SHA-256。
3. 选择“安装固件”并确认操作。
4. 保持车辆静止，等待最终结果。

App OTA 不进入 ROM 恢复模式，也不会擦除或改写 NVS。当前运行固件支持时，
可读的 24 项设置导出作为额外诊断备份。如果当前固件不提供 OSR App OTA，
请选择完整烧写镜像，再通过 BOOT/RESET 恢复模式安装。

## 安装完整烧写镜像

1. 选择完整烧写文件，核对类型和 SHA-256。
2. 选择“完整烧写”。
3. 按 BOOT/RESET 提示进入恢复模式。
   控制器会重新枚举为另一个串口，OSR Updater 将按照同一物理 USB 连接自动发现，
   并在控制器串口栏显示实际 ROM 串口。
4. 点击“打开备份”，确认当前完整设置备份已经保存。
5. 备份完成后会自动显示最终破坏性操作确认；确认后继续。
6. 保持电源和 USB 连接，直到显示写入结果。
7. 写入后按提示按一次 RESET。串口列表会自动刷新，随后点击“检查设备”。

备份和安装是一个引导操作。备份成功后，在核对最终确认期间让控制器继续保持
恢复模式，不要按 RESET 或断开 USB。取消最终确认会保留备份且不擦除控制器；
再次选择“完整烧写”即可继续现有流程。

只要文件是结构有效的 ESP32-S3 合并镜像，即使目标使用客户自定义分区布局也
允许烧写。只有以下内容全部匹配时，客户端才会自动恢复刚刚读取的设置：

- 当前控制器身份；
- 设置分区偏移和大小；
- 备份文件的所有者、权限、大小和 SHA-256。

写入后会逐字节回读比较。目标布局不兼容时只保留备份，不会向未知布局写入。
完整烧写结束后不等待 OSR 协议响应，避免客户独立开发、未实现该接口的固件造成
无意义等待。

## 恢复出厂

1. 选择需要安装的完整烧写固件。
2. 查看出厂车辆设置基准。客户端会按所选固件的 NVS 布局自动过滤。
3. 选择“恢复出厂”。
4. 按 BOOT/RESET 提示进入恢复模式，确认组合执行固件安装和车辆设置恢复。
5. 保持电源和 USB 连接，直到显示回读结果。

写入前，客户端会核对元数据和数据哈希、文件权限、ESP32-S3 设备身份，以及当前
目标固件的 NVS 分区偏移和大小。随后先将当前 NVS 另存为安全快照，安装所选完整
固件，再写入所选备份，完整回读并逐字节比较。来自其他控制器或与目标固件布局
不一致的备份会在擦除前被拒绝。

每次破坏性操作前仍会读取并校验车辆设置。同一控制器、同一分区布局且原始内容
SHA-256 相同时不会重复保存大文件；具有已知来源固件的最早有效操作快照固定为
该控制器和 NVS 布局的出厂基准，后续快照仅作为审计证据保留。

## 结果说明

- **操作成功完成**：要求的写入和回读检查已经完成。完整烧写后请按一次 RESET，
  再点击“检查设备”单独确认运行固件。
- **写入已完成，需确认控制器启动状态**：写入已经完成，但客户自定义启动、
  身份或可选设置检查无法确认。保留备份，不要自动重复 App 写入。
- **操作需要处理**：写入前条件不满足，处理提示的问题后可重新执行完整烧写。
- 无法检查固件时，界面会清空此前显示的固件版本和接口协议，并保留用户选择的
  串口。ROM 下载模式或独立开发固件可能没有实现 OSR 检查命令。
- 完整擦除开始后如果失败，必须保留受保护备份，并按客户端恢复提示处理。

## 备份和审计文件

文件使用仅当前用户可读写的权限，保存于：

```text
~/.local/state/osr-updater/
```

点击“打开备份”和审计日志旁的“打开”按钮，可直接打开固定状态文件夹。该目录
包括可读设置导出、完整 NVS 快照和只追加审计记录。每份 `.bin` 快照应与相邻的
`.json` 元数据文件及对应控制器的维修记录一起保留。
